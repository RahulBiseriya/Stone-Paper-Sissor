# 🪨 📄 ✂️ Stone Paper Scissors Game

A classic, interactive, and beautifully designed **Stone Paper Scissors** web game built using HTML, CSS, and JavaScript. Challenge the computer, test your luck, and enjoy a sleek user interface with a modern dark theme and glowing mystical elements.

[Live Demo Link](https://rahulbiseriya.github.io/Stone-Paper-Sissor/) ---

## 🚀 Features

* **Modern UI:** A clean, dark-themed interface featuring unique mystical card designs for Stone, Paper, and Scissors.
* **Flexbox Layout:** Perfectly centered gameplay area with responsive image scaling (`object-fit: cover`).
* **Fully Responsive:** Designed to scale beautifully across different screen sizes, from mobile phones to large desktop monitors.
* **Dedicated Legal Page:** Includes a professionally stylized, semi-transparent *Terms & Conditions* page built directly into the user flow.

---

## 🛠️ Tech Stack

* **HTML5:** Structural layout of the game board and documentation.
* **CSS3:** Flexbox positioning, glassmorphism design effects, custom scrollbars, and smooth hover transitions.
* **JavaScript (ES6):** Game logic, score tracking, and automated AI opponent moves. *(Ready to be wired up!)*
